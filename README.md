## Featured project

### [OPL-DualSense-USB](https://github.com/kxlyoo/OPL-DualSense-USB)
A fork of [OPL-DualSense-BT](https://github.com/rodrigoGalvanDev/OPL-DualSense-BT) that adds **wired DualSense support over USB** in-game on the PS2 (Open PS2 Loader + PADEMU).

Built entirely from the browser using GitHub Codespaces and Actions, with a PS2 fat and a USB HDD as the test bench.
